# HTML Vibe Board Template Guidelines

When `--html` is passed to `vibe-storm`, output an interactive, single-file HTML document.

## Architecture

- **Zero External Dependencies:** Built with pure HTML5, CSS3, and vanilla JavaScript.
- **Glassmorphism Dark Theme:** Modern developer/founder aesthetics matching Vercel and Linear styles.
- **Interactive Tabs:**
  - Business Canvas (`#biz`)
  - Marketing Matrix (`#mkt`)
  - Content Sprint (`#content`)
  - 48h Sprint Kanban (`#sprint`)
- **Copy-to-Clipboard Snippets:** Every prompt block has an instant `Copy Prompt` button with visual feedback.
- **Persistent Checklists:** Checkboxes in the sprint roadmap toggle visual completion.
